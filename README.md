# Планировщик задач (TODO-лист) на Go

## Описание проекта

Веб-сервер для управления задачами с поддержкой дедлайнов, комментариев и гибких правил повторения (ежедневно, еженедельно, ежемесячно, ежегодно). Проект реализует REST API, взаимодействует с базой данных SQLite и имеет готовый фронтенд-интерфейс.

## Выполненные задания со звёздочкой

- [x] Чтение порта и пути к БД из переменных окружения (`TODO_PORT`, `TODO_DBFILE`).
- [x] Поддержка сложных правил повторения: дни недели (`w 1,4`) и дни месяца (`m 1,-1`).
- [x] Поиск задач по подстроке в заголовке/комментарии и по конкретной дате (`DD.MM.YYYY`).
- [x] Реализация механизма аутентификации через JWT-токены и middleware.
- [x] Создание Docker-образа и инструкции по запуску.

## Локальный запуск

1. Убедитесь, что у вас установлен Go 1.21+.
2. Склонируйте репозиторий и перейдите в папку проекта.
3. Установите зависимости: `go mod tidy`
4. (Опционально) Задайте переменные окружения:
   ```bash
   export TODO_PORT=7540
   export TODO_PASSWORD=mysecretpassword
   ```
